**Application Control Manager - Административная утилита
Описание проекта**
Административная WPF-утилита для управления службой контроля приложений (Application Control Service). Предоставляет графический интерфейс для работы с белым списком приложений, просмотра логов и управления службой Windows.

**Основные возможности
📋 Белый список приложений**
Добавление приложений в белый список по SHA-256 хэшу
Просмотр списка разрешенных приложений
Удаление приложений из списка
Автоматическая перезагрузка конфигурации службы при изменениях

**📊 Управление логами**
Просмотр логов в блокноте Windows
Очистка логовых файлов
Поддержка разных типов логов (detailed, service, terminations)
Настройка пути хранения логов

**⚙️ Управление службой**
Установка и удаление службы Windows
Запуск/остановка службы
Просмотр статуса службы в реальном времени
Режим отладки
Настройка путей для логов и конфигурации

**Структура проекта
Основные компоненты**
**Менеджеры (Managers/):**
ServiceManager.cs - управление службой Windows
WhiteListManager.cs - работа с белым списком
LogReader.cs - чтение и управление логами

**Страницы (Pages/):**
WhiteListPage.xaml - страница белого списка
ServicePage.xaml - страница управления службой
LogsPage.xaml - страница работы с логами

**Утилиты (Utils/):**
HashUtils.cs - вычисление и валидация хэшей SHA-256
IndexConverter.cs - конвертер для отображения индексов

**Модели:**
WhiteListItem.cs - модель элемента белого списка

**Требования**
.NET Framework 4.7.2 или выше
Права администратора для установки/удаления службы
Windows 7 или выше
Visual Studio 2019/2022 для разработки
